## 阅读约定：核实状态

这几份分析共同遵循一套标注方式，目的是**把「查到的」与「推断的」分开**：

| 标注 | 含义 |
|---|---|
| **已核实** | 有公开来源，正文附链接 |
| **分析重建** | 依照片或公开图像反推绘制的图版 |
| **分析推断** | 基于建筑常识的推理，非官方表述 |
| **无公开依据** | 该项留白，**不以推测数字填充** |

几点具体做法：

- 所有 **SVG 图版均为分析绘制的图解**，不是设计方原始图纸；涉及比例的一律标注「分析重建」。
- 当公开资料互相矛盾时（如阿纳姆博物馆的建筑面积、隆平水稻博物馆的总建筑面积），**各口径并列列出并注明出处**，不擅自裁定。
- 官方未公开的参数（结构构件规格、跨度、层高、耐火等级、造价单价等）一律留白。此前流传的若干具体数字（如 `H400x200x8x12`、跨度 24m）经核查**无施工图依据**，已剔除。

## 技术说明

- **单文件交付**：每份 HTML 内嵌全部资源。字体以 base64 内嵌，图片以 data URI 内嵌。
- **零依赖**：无 CDN、无框架、无构建。WebGL 彩窗与粒子效果均为原生 WebGL/Canvas 实现。
- **响应式**：适配桌面至手机视口。
- **无障碍**：支持 `prefers-reduced-motion`（开启后关闭粒子、视差与自动播放动效）；提供打印样式。
- **键盘可达**：灯箱支持 `←` `→` 切换、`ESC` 关闭；可展开卡片支持 `Enter` / `Space`。
